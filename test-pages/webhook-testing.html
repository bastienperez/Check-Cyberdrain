🔗 Webhook Format Testing

Test different webhook formats for the Check Extension. This page simulates webhook payloads and shows you how they would appear in Slack, Microsoft Teams, or as JSON.

⚠️ Testing Note
This page generates sample webhook payloads based on the actual extension data structure. Use these examples to test your webhook endpoints before deploying the extension.
🔧 Configuration Instructions

To configure webhook formatting in your extension:

  1. Open the extension options page (click the extension icon → Options)
  2. Go to General Settings section
  3. Find the Webhook Notifications configuration
  4. Set your webhook URL and choose the format:
    • JSON - Raw structured data for custom integrations
    • Slack Block Kit - Rich formatted cards for Slack channels
    • Microsoft Teams Adaptive Cards - Formatted cards for Teams channels
  5. Select which event types to send (Page Blocked, Detection Alert, etc.)
  6. Save settings
📄 JSON Format (Default)

Standard structured JSON payload for custom integrations.

{ "genericWebhook": { "enabled": true, "url": "https://api.example.com/webhooks", "format": "json", "events": ["page_blocked", "detection_alert"] } }
